# Minidoracat Pack & Throw（丟出收納）

把停著的車收進膠囊，丟出去就原樣出現；活著的動物改用帕魯球抓，抓到的動物放出時直接出現在你身旁；空膠囊與空帕魯球丟向車或動物也能直接抓進去。車的改裝、車況與貨物，動物的品種、年齡、基因與懷孕都一起保存；收起來的車不在世界上，KI5 這類吃效能的車也能收起來減輕負擔。單人與多人皆可用。

舊名：萬用膠囊（Universal Capsule，舊 Mod ID `MinidoracatCapsuleFor42`），更早叫車輛膠囊（Vehicle Capsule，舊 Mod ID `MinidoracatVehicleCapsuleFor42`），都在首發前改名，目前的 Mod ID 是 `MinidoracatPackThrowFor42`；GitHub repo 也跟著改名成 `Minidoracat/MinidoracatPackThrowFor42`（舊網址會自動轉到這裡）。

Project Zomboid Build 42 MOD。**尚未發布**（首發版 `42.21.0-0.1.0` 準備中）。

帕魯球的名稱與外觀致敬《幻獸帕魯》，本 MOD 與 Pocketpair 無關。

## 需要

- [Minidoracat UI Library](https://steamcommunity.com/sharedfiles/filedetails/?id=3789836701)（必裝：3D 預覽與管理面板）
- [Minidoracat Vehicle Manager](https://steamcommunity.com/sharedfiles/filedetails/?id=3813972279)（選用：綁定的車只有車主和被分享「拖曳」權限的人能收，展開後車主不變）
- [Minidoracat Economy](https://steamcommunity.com/sharedfiles/filedetails/?id=3801482125)（選用：管理員把空膠囊與空帕魯球上架到經濟中心販售；有裝新版時，裝了車的膠囊與裝了動物的帕魯球可以在市場上架或拍賣）

## 功能

- **收車**：右鍵車輛「收進膠囊」，約 10 秒；條件是引擎熄火、車上沒人、背包有空膠囊（有兩種以上時從子選單選款式）。選單逐項列出條件，沒符合的寫出要怎麼做。權限：在 Vehicle Manager 綁定的車只有車主和被分享「拖曳」權限的人能收（管理員要開越權）；其他車照沙盒（預設要有車鑰匙，可改任何人或只有管理員），管理員一律可收。沒權限時選項前面有減號、點了跳通知寫原因。
- **原樣保存**：車種、塗裝、零件與車況（含改裝與拆掉的零件）、油量、胎壓、電瓶、門窗與門鎖、鑰匙編號，以及車上所有貨物（用原物件保存，水量、新鮮度、血跡都在）。原版車與 KI5 車都實測過。
- **丟出展開**：物品欄右鍵「丟出膠囊」，游標框出車身（綠框放得下、紅框寫原因），游標開著時站著的角色先轉向瞄準處，按下就丟；丟出「咻～」、落地冒煙閃光，車原樣出現，貨物放回原容器；可設定歸還一顆同款空膠囊。
- **按下按鈕**：貨物太重、膠囊撿不起來時，對地上的膠囊「按下按鈕」，車出現在旁邊。
- **貨物鎖**：裝了車的膠囊不能直接拿出貨物（拖曳、全部拿取、吃喝、裝填、製作都拿不到），要展開車才拿得到；伺服器也會把被硬拿出的貨物放回。沙盒選項「可以從膠囊拿出貨物」開啟時改成只能拿出、不能放進去，拿走的從紀錄刪掉；剛收好與當機前未確認的膠囊照樣鎖住。
- **提示框與 3D 預覽**：滑鼠移到膠囊上看款式、車名、車況、油量、電瓶、缺件、改裝與貨物；右鍵「預覽車輛」旋轉查看車種外觀。裝了車的膠囊名稱是「款式：車名」，每位玩家看到自己的語言。
- **當機不複製**：收車與展開後約 5 秒才標成已存好；當機前未確認的紀錄由管理員到現場判定，確定落盤的舊膠囊裡多出來的貨物會自動清掉。
- **紀錄與補回**：每顆膠囊只能展開一次，每次收車、展開、拒絕、補回都有紀錄；管理面板（家族工具列「丟出收納管理」）可搜尋、看時間軸與貨物清單、前往紀錄位置、補回車輛（只補車，貨物列清單由管理員決定）。
- **取得方式**：戰利品（膠囊在修車廠、汽車用品店、加油站修車區、住家車庫（預設關），每個地點的量由開著的款式平分；帕魯球在穀倉、寵物店、獵人置物櫃，四級照稀有度 8:4:2:1 分；七個地點各自開關與權重，管理面板也能改）、管理員發放、經濟中心上架。
- **七種膠囊**：卡通、寫實、塵土、蒸汽、科幻、魔法、衝擊，配色、煙霧與四段音效各不相同，功能一樣，膠囊只收車。管理面板「種類」分頁可以逐種關掉收車或戰利品、在身旁預覽、在經濟中心建立商品草稿，四級帕魯球也在同一個分頁。煙霧與閃光只畫在畫面上；聲音預設不引殭屍，可用沙盒調範圍。
- **帕魯球抓動物**：動物改用帕魯球抓，膠囊只收車。右鍵世界上活著的動物，在那隻動物的子選單選「收進帕魯球」，約 10 秒；家養與野生、成年與幼崽都能收，誰都能收。能馴養的野生動物收進去就變成家養（照原版抱起動物），鹿這類照舊是野生。死掉、掛在屠宰鉤上、被抱著、在畜欄或拖車裡的不能收，綁著繩子的要先解開。
- **四級帕魯球**：帕魯球、高級帕魯球、優質帕魯球、傳奇帕魯球（藍、綠、黃、紫），抓野生動物的等級加成 +0／+15／+30／+50，戰利品稀有度 8:4:2:1；四級共用科幻款的煙霧與音效。
- **動物保存什麼**：名字、品種、性別、年齡、體型與體重、健康、飢餓與口渴、壓力、基因與遺傳疾病、奶量、羊毛、懷孕與受精。帕魯球裡時間靜止（帕魯球提示框最後一行也寫著）：不會長大、不會餓或渴，懷孕也會暫停。原版的擠奶與撫摸間隔、當天下蛋數、繁殖冷卻會重新開始；多人時毛色花紋由每位玩家的遊戲各自決定（原版行為）。
- **放出動物**：物品欄右鍵「放出：名字」，短短的動作後動物出現在你面向的那一格，不行就身旁其他格，落點只要一格空地（不能是水、車底、樹或沒有地面），室內可以；八格都不行寫「旁邊沒有空地」、帕魯球留在背包，在車上不能放。帕魯球不能丟出，地上的也沒有「按下按鈕」。放出後拿回同等級空帕魯球（沙盒「展開後歸還空膠囊或空帕魯球」）。提示框列出動物資料（懷孕照原版只給畜牧 3 級以上看）；裝了動物的帕魯球沒有 3D 預覽。管理面板可補回動物。
- **管理員開關**：沙盒「可以抓動物」（預設開，管理面板「設定」分頁也能改）只擋抓動物，已經裝了動物的帕魯球照樣能放出與補回。
- **野生動物的成功率**：只對野生動物，成功率＝基本（沙盒「抓野生動物基本成功率」，預設 50）＋等級加成＋受傷（預設 30，按少掉的健康比例）＋幼崽（預設 15）＋沒發現你（預設 20：牠沒在警戒而且你在潛行或在牠背後），上限 100；三個加成可各自設 0 關掉，都在沙盒與管理面板「設定」分頁調整。選單收與丟出抓取野生動物時由伺服器擲骰，家養動物和車一律成功。動物選單與抓取游標的提示框寫出「成功率：77%」與下一列加成，游標上的數字是估計，丟中那一刻由伺服器決定；沒抓到時動物掙脫、留在原地，通知寫「牠掙脫了（成功率 50%）」，空帕魯球不會用掉（丟出的掉在落點）。沙盒「沒抓到時帕魯球消失」（預設關）打開時，掙脫那次的空帕魯球也消失，提示框與通知會寫出來；其他沒抓到的情況照舊。基本成功率設成 0 不能抓野生動物（加成救不回來），100 一定成功。
- **丟出抓取**：物品欄右鍵空膠囊或空帕魯球「丟出抓取」，膠囊只認車、帕魯球只認動物，丟向游標格或旁邊一格的目標（約 8 格內、看得到），落地就收進去，裝好的膠囊或帕魯球落在目標原本的位置；不用走過去、不用等 10 秒，看到人會跑的野生動物用丟的最好抓。游標綠框寫目標名稱、紅框寫原因（拿錯會寫「膠囊收不了動物，要用帕魯球」或「帕魯球收不了車」）；規則跟選單收一樣（車要同樣的權限：Vehicle Manager「拖曳」、沙盒「誰能收車」）。落地時伺服器在落點一格內再找目標、再驗一次，目標跑開或狀態變了就沒中，空球掉在落點。
- **安全屋保護**：多人伺服器上，別人安全屋裡的車和動物不能用選單收、不能抓，也不能丟出膠囊、按下按鈕、在那裡放出動物或由管理員補回到那裡（收看動物那格與車身壓到的格子，放看落點範圍）。屋主、成員、有原版安全屋權限的管理人員與戰爭期間照原版不受限。丟出前就被拒，球留在背包；落地時才被拒，丟出的掉在丟的人腳下，不會掉進別人的安全屋。
- **經濟中心**：裝了車的膠囊連貨物、裝了動物的帕魯球連動物資料都能在市場上架或拍賣（需要新版 Minidoracat Economy），不能用求購單收、不能賣給商店；空帕魯球是一般商品。

## 給服主

- 伺服器紀錄存在 `Zomboid/Lua/MinidoracatPackThrow/<世界>/`（不在世界存檔裡，每個伺服器／單人存檔一個資料夾，最多 513 個檔）；收起中的車和動物只能靠它補回，請和世界存檔一起備份、一起還原。已結束的紀錄預設保留 30 天（沙盒「結束紀錄保留天數」，1–90）。
- 用 Minidoracat Cleaner 時，把七種裝了車的膠囊 `MinidoracatPackThrow.LoadedCapsuleCartoon`、`LoadedCapsuleReal`、`LoadedCapsuleDust`、`LoadedCapsuleSteam`、`LoadedCapsuleSciFi`、`LoadedCapsuleMagic`、`LoadedCapsuleShock`，以及四個裝了動物的帕魯球 `MinidoracatPackThrow.LoadedSphereBasic`、`LoadedSphereMega`、`LoadedSphereGiga`、`LoadedSphereLegend` 加進「物品保護清單」（ProtectList），地上裝了東西的膠囊與帕魯球就不會被清掉。
- 物品 ID：空膠囊 `MinidoracatPackThrow.Capsule<款式>`（上架、發放用）、裝了車的膠囊 `MinidoracatPackThrow.LoadedCapsule<款式>`、空帕魯球 `MinidoracatPackThrow.Sphere<等級>`、裝了動物的帕魯球 `MinidoracatPackThrow.LoadedSphere<等級>`（裝了東西的都不能用求購單收、不能賣給商店）；款式是 `Cartoon`、`Real`、`Dust`、`Steam`、`SciFi`、`Magic`、`Shock`，等級是 `Basic`、`Mega`、`Giga`、`Legend`。

## 開發

- `link_workshop.bat`：手動同步、唯讀狀態與歸檔卸載；MOD 以實體副本放入 `Zomboid\Workshop\` 與 `Zomboid\mods\`，不使用目錄連結
- `PZ_Test.bat`：暗色點選視窗，啟動前增量同步目前 MOD 與家族依賴；首次預設 no-Steam，之後記住各專案的選擇。需要換檔但遊戲仍在執行時拒絕同步與新啟動，不停止既有遊戲；完整驗證與資料邊界見 `../pz-family-docs/tools.md`
- 提交／發版前閘門（repo 根目錄，任一 FAIL 不得定版）：`uv run scripts/verify_mod.py`（靜態檢查，見 [`scripts/verify_mod.py`](scripts/verify_mod.py)）與 `lua scripts/smoke_harness.lua`（行為測試：紀錄存取、狀態轉換、當機判定、補回、貨物鎖，見 [`scripts/smoke_harness.lua`](scripts/smoke_harness.lua)）
- 實機 E2E：照 `../pz-family-docs/e2e.md` 的流程跑專用伺服器＋客戶端；本 repo 的情境放在本機技能 `.claude/skills/packthrow-e2e/`（不入庫）。改到網路指令、伺服器寫檔、沙盒、權限或介面時補情境並跑一次。
- `Publish_Workshop.bat`：發布到 Steam Workshop（需 Steam 用戶端已登入；可選擇只更新內容／封面／簡介；首發仍走遊戲內上傳器）
